먼저먹자 데이터 삭제 안내

먼저먹자는 사용자 계정을 운영하지 않으며, 식재료 정보와 설정 데이터는 사용자 기기 내부에 저장됩니다.

사용자는 다음 방법으로 데이터를 삭제할 수 있습니다.

  • 앱 내 개별 식재료 삭제 기능 사용
  • 앱 내 소비 완료 항목 일괄 삭제 기능 사용
  • 기기에서 앱 삭제

앱 삭제 시 저장된 로컬 데이터는 함께 제거될 수 있습니다.

먼저먹자는 별도의 자체 서버에 사용자 데이터를 저장하거나 보관하지 않습니다.
